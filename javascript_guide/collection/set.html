JavaScript Set

A Set is a collection that stores unique values.

A Set does not allow duplicate values. 

const numbers = new Set();

numbers.add(10);
numbers.add(20);
numbers.add(10);

console.log(numbers);

Output: 

Set(2) {10, 20}

Notice that 10 was added twice, but Set kept only one 10.

1. Create a Set

const ids = new Set();

console.log(ids);

2. Create Set with Initial Values

const ids = new Set([2, 4, 5, 6]);

console.log(ids);

3. add() — Add Value

add() is used to add a value to a Set. 

const cars = new Set();

cars.add("BMW");
cars.add("Mercedes");
cars.add("Audi");
cars.add("Porsche");

4. Duplicate Values

Set automatically removes duplicate values. 

const numbers = new Set();

numbers.add(10);
numbers.add(20);
numbers.add(10);
numbers.add(20);
numbers.add(30);

5. delete() — Remove Value

const cars = new Set([
    "BMW",
    "Mercedes",
    "Audi"
]);

cars.delete("Mercedes");

6. has() — Check Value

const numbers = new Set([
    10,
    20,
    30
]);

numbers.has(20);
numbers.has(100);

7. values() — Get Values

const vegetables = new Set([
    "Carrot",
    "Potato",
    "Onion"
]);

for (const vegetable of vegetables.values()) {
    console.log(vegetable);
}

8. for...of — Loop Through Set

const fruits = new Set([
    "Apple",
    "Banana",
    "Orange"
]);

for (const fruit of fruits) {
    console.log(fruit);
}

9. entries() — Get Entries

Set entries() is [value, value] return 

const numbers = new Set([
    10,
    20,
    30
]);

const entries = numbers.entries();

console.log(entries.next().value);

10. forEach() — Loop Through Set

const fruits = new Set([
    "Apple",
    "Banana",
    "Orange"
]);

fruits.forEach((value) => {
    console.log(value);
});

11. clear() — Remove Everything

const numbers = new Set([
    10,
    20,
    30
]);

numbers.clear();

console.log(numbers);

12. size — Number of Values

const numbers = new Set([
    10,
    20,
    30,
    40
]);

console.log(numbers.size);

13. Set Can Store Different Data Types

const data = new Set();

data.add(100);
data.add("Hello");
data.add(true);
data.add(null);
data.add(undefined);

14. Remove Duplicate Values from Array

This is one of the most useful real-world uses of Set. 

const numbers = [
    10,
    20,
    10,
    30,
    20,
    40
];

const uniqueNumbers = [
    ...new Set(numbers)
];

console.log(uniqueNumbers);

15. Convert Set to Array

const numbers = new Set([
    10,
    20,
    30
]);

const array = [...numbers];

Set Methods Summary

new Set()       → Create Set

add()           → Add value
delete()        → Delete value
has()           → Check value
clear()         → Delete everything

values()        → Get values
entries()       → Get [value, value]
forEach()       → Loop through Set

size            → Number of values
