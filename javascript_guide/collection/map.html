JavaScript Map

A Map stores data as key-value pairs.

Example: 

            const students = new Map();

            students.set(101, "Rahul");
            students.set(102, "Amit");
            students.set(103, "Neha");

1. Create a Map

const students = new Map();

console.log(students);

2. set() — Add Data

set(key, value) adds a key-value pair. 

students.set(101, "Rahul");
students.set(102, "Amit");
students.set(103, "Neha");

3. get() — Get Value

students.get(102);

4. has() — Check Key

students.has(102);
students.has(999);

5. delete() — Remove Data

students.delete(102);

6. keys() — Get All Keys

students.keys();

7. values() — Get All Values

students.values();

8. entries() — Get Key + Value

students.entries();

9. for...of — Loop Through Map

for (let [key, value] of students) {
    console.log(key, value);
}

10. forEach() — Loop Through Map

students.forEach((value, key) => {
    console.log(key, value);
});

11. Duplicate Key

Map cannot have duplicate keys. If the same key is used again, the value is updated. 

const users = new Map();

users.set(1, "John");
users.set(1, "David");

console.log(users.get(1));

12. Duplicate Values

Map can contain duplicate values. 

const employees = new Map();

employees.set(1, "John");
employees.set(2, "John");
employees.set(3, "David");

13. Any Data Type Can Be a Key

const map = new Map();

map.set("name", "Hein");
map.set(100, "Number Key");
map.set(true, "Boolean Key");

14. Object as a Key

const user = {
    id: 1,
    name: "Hein"
};

const map = new Map();

map.set(user, "User Data");

console.log(map.get(user));

15. size — Number of Elements

students.size

16. clear() — Remove Everything

students.clear();

Map Methods Summary

new Map()       → Create Map

set()           → Add / Update
get()           → Get value
has()           → Check key
delete()        → Delete one key
clear()         → Delete everything

keys()          → Get keys
values()        → Get values
entries()       → Get key + value
forEach()       → Loop through Map

size            → Number of elements
